What it does

Everything you need to know
about medicinal plants

PhytoMed combines a curated database, semantic TF-IDF vector search, and a clean REST API — all accessible from the desktop app or any browser.

🔍

Semantic Search

TF-IDF vector search lets you find plants and diseases by describing symptoms in natural language — not just exact keywords.

🌿

Plant Profiles

Full plant entries including Latin name, geographic location, Cameroon-specific habitats, medicinal use, application steps, precautions, and toxicity.

💊

Disease-to-Remedy

Each disease links to the plants that treat it, with specific preparation methods and which part of the plant to use.

📡

REST API Backend

FastAPI server exposes all data over HTTP — your PC acts as both server and client, and any browser or app can consume the same endpoints.

⚡

Autocomplete

Real-time disease and plant name suggestions as you type, powered by the /autocomplete endpoints.

🖥️

Desktop App

Beautiful Kivy desktop client with dark theme, smooth transitions, expandable remedy cards, and filter chips — all talking to the local API.

How it works

API-First Architecture

The UI never touches the database directly. Every request flows through the REST API, giving a clean separation of concerns and making the data available to any client.

🔄 Our Scrum Process

We ran 2-week sprints, opening each with sprint planning to pull items from the product backlog into the sprint backlog. Daily stand-ups kept everyone in sync. Sprint reviews demoed working features — including live API calls from the desktop app — and retrospectives continuously improved our workflow. The API-first architecture was decided in Sprint 1 as the highest-value technical story.
